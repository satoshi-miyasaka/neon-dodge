# ネオン・ドッジ (Neon Dodge)

上から落ちてくるブロックを避け続けるシンプルなブラウザゲームです。時間が経つほどブロックの落下速度と出現頻度が上がっていきます。何秒生き残れるか挑戦しましょう。

## 遊び方

`index.html` をブラウザで直接開くだけで遊べます。サーバーは不要です。

```bash
start index.html
```

## 操作方法

- `←` / `→` キー、または `A` / `D` キーで移動
- 画面をドラッグ(タッチ操作)しても移動できます

## 特徴

- ベストスコアはブラウザの `localStorage` に保存されます
- スマートフォンなどのタッチ操作に対応
